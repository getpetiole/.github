# Code of conduct

Petiole's open-source projects follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, assume good intent, and keep discussion about the work.

Report behaviour that breaks it to support@petioleapp.com, with "Code of
conduct" in the subject. Reports are read by Petiole's maintainers and
kept confidential.
