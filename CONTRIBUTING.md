# Contributing

Thank you for helping. Petiole's public repositories take issues and pull
requests.

- **A bug**: open an issue with what you did, what you expected, what
  happened, and the request's id (`request-id`) if the API answered.
  Never paste an API key: revoke one you shared by mistake on Keys &
  access, then make another.
- **A change**: open an issue first for anything larger than a fix, so we
  agree on it before you spend time. Keep a pull request to one change,
  with tests, and say how you checked it.
- **A starter**: a starter stays small and copyable. A feature belongs in
  it when most people building on it would keep it.
- **Security**: never in an issue; see [SECURITY.md](SECURITY.md).

By contributing you agree that your contribution is licensed under the
repository's licence (MIT for the starters).
